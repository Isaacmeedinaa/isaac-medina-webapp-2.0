how is my work

process flow

  • what is the problem?
  • ui/ux design
  • development

Before designing and development, I always detect what is the problem I need to solve. Whether it is a customers website, or a company project, there is always a problem to fix and make better.

I then decide what is the best approach to solve this problem. Examples of problems that I have solved had been, "How can I make a nice website for my business?" or "How can we make this app more stable?".

User interface and User experience is one of my biggest concerns when making a website or mobile app. This also includes the user experience. Without a nice user interface, the user experience isn't very good. Without a nice user experience, the user interface is useless.

In order to make a great user interface and user experience, I first decide what user interface does the client or company match. Depending on that, I design the user experience smooth, and clean.

After a nice UI/UX is brainstormed, I decide which technologies are the best fit for the project. This will determine how the app will be built and with what languages.

If it's a simple website for a client, I will use basic web design tools. If it's a larger app that requires server-side code, I will use MEAN Stack, or other type of technologies.
